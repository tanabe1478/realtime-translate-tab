# Realtime Translate

Windows-firstのリアルタイム文字起こし・翻訳Webアプリです。YouTubeをアプリ内に埋め込み、動画と原文・翻訳を1つのタブで表示できます。マイク、音声・動画ファイルも入力できます。

## 処理構成

```text
ブラウザ音声
  → ローカル faster-whisper（直前文脈を使った文字起こし）
  → 未完結チャンクの発話結合
  → 選択した翻訳モデル（OpenAI認証 / OpenCode Go APIキー）
  → WebSocketで暫定／確定字幕表示
```

音声認識に外部APIキーは使いません。翻訳と話題・用語集生成は、`.env`で**OpenAI認証**または**OpenCode Go APIキー**を明示的に選びます。OpenAIでは既存のChatGPTサブスクリプションのログインを引き続き利用でき、通常のOpenAI APIキー方式も残しています。認証エラーや利用枠不足を理由に、別の接続先へ自動切り替えはしません。

## 現在のMVP

- YouTube URLからページ内に動画を埋め込み（通常URL・短縮URL・Shorts・ライブ・開始時刻に対応）
- 埋め込み動画を含むアプリ自身のタブ音声を`getDisplayMedia()`で取得
- マイク音声を`getUserMedia()`で取得
- 16 kHz mono WAVを5秒単位で生成
- 送信前にIndexedDBへ保存
- WebSocketのACK後にローカルチャンクを削除
- サーバーでは音声を先にファイル保存し、SQLiteへ記録
- 切断時の再接続・再送、サーバー側の重複排除
- ローカル`faster-whisper`による文字起こし
- 話題・用語集を動画情報から自動生成し、実際の発言からバックグラウンド更新
- 用語集の原語と直前の認識文をWhisperへ渡し、専門用語と固有名詞を継続
- 話題・用語集の確認・手動修正、自動更新への復帰、動画・翻訳先ごとの永続保存
- 文末、無音、15秒上限を使って5秒チャンクを発話単位へ結合
- 未完結の発話は暫定字幕、結合後は確定字幕として表示
- 直近6発話の原文・訳文を参照する文脈付き翻訳
- OpenAI（ChatGPT OAuth / APIキー）とOpenCode Go APIキーの明示的な切り替え
- 選択中の接続先・モデル・認証方式を画面に表示（キー自体はブラウザへ送らない）
- 25 MB以下の音声・動画ファイル入力

## 必要環境

- Node.js 24（`node:sqlite`を使用）
- pnpm 10
- Python 3.10〜3.12
- タブ音声共有に対応したデスクトップ版Chrome・Chromium・Edge（Firefox/Safariは画面共有の音声取得に未対応。Linuxではブラウザタブの音声を共有し、実際の共有ダイアログ・再生動作は手動で確認してください）
- 選択するプロバイダーの認証と利用権限（ChatGPTログイン、OpenAI APIキー、またはOpenCode Go APIキー）

## 初回セットアップ

```powershell
copy .env.example .env
pnpm install
pnpm whisper:setup
# 以下の「翻訳プロバイダー」で接続先と認証を設定
```

Ubuntuでは`copy`の代わりに`cp .env.example .env`を使います。`pnpm`が見つからずCorepackが入っている場合は、先に`corepack enable`を実行してください。Pythonはこのプロジェクトの想定する3.10〜3.12を用意します。

### UbuntuのPythonが3.13以降の場合

OS標準のPythonを置き換える必要はありません。Whisper用だけPython 3.12にします。[uv](https://docs.astral.sh/uv/getting-started/installation/)をユーザー領域へインストール済みなら、**`.venv-whisper`がまだない場合に限り**次で作成できます。

```sh
export PATH="$HOME/.local/bin:$PATH"
uv python install 3.12
uv venv --python 3.12 --seed .venv-whisper
pnpm whisper:setup
```

セットアップは既存の`.venv-whisper`を優先し、次に`.env`の`WHISPER_PYTHON`、またはPython 3.12 / 3.11 / 3.10を探します。3.13以降を誤って使わず、既存環境を勝手に削除もしません。`pnpm`が見つからない場合は`corepack enable --install-directory "$HOME/.local/bin" pnpm`でユーザー領域へコマンドを用意できます。

### 翻訳プロバイダーの切り替え

`.env.example`を`.env`にコピーし、**ローカルのエディター**で設定します。Ubuntuではプロジェクトのフォルダーで`nano .env`を実行して編集できます。キーをチャットやIssueに貼らないでください。`.env`と`data/auth.json`はGit管理から除外されます。

**OpenAIのログインを使う場合（従来の方式・未指定時の既定値）:**

```env
TRANSLATION_PROVIDER=openai
OPENAI_TRANSLATE_MODEL=gpt-6-luna
```

```sh
pnpm auth:openai
```

表示されるURLをブラウザで開き、ChatGPTへサインインします。資格情報は`data/auth.json`へ保存されます。Goへ切り替えても、このファイルは変更・削除しません。`TRANSLATION_PROVIDER=openai`へ戻してサーバーを再起動すれば、保存済みログインを再利用できます（期限切れ等では再認証が必要です）。

OpenAIの通常APIを使う場合は、OAuth未ログインの状態で`.env`に`OPENAI_API_KEY`を設定します。保存済みOAuthがある場合はそちらが優先されます。APIキー方式へ明示的に変更するなら`pnpm auth:openai:logout`でOAuthを解除します。OpenAI APIの料金はChatGPTサブスクリプションとは別です。

**OpenCode Goのキーを使う場合:**

```env
TRANSLATION_PROVIDER=opencode-go
OPENCODE_API_KEY=ここをローカルで自分のキーに置き換える
OPENCODE_TRANSLATE_MODEL=glm-5.3-flash
```

Go用にOpenAIログインを実行する必要はありません。初期候補は公式のモデル一覧にある`glm-5.3-flash`です。重いモデルを常用するより字幕向けの候補として採用していますが、日本語訳の品質や遅延は実測比較が必要です。`glm-5.3`など、インストール済みSDKのGoカタログにあるモデルへ変更できます。Goの未知のモデル名・プロバイダー名はエラーにし、別モデル・別接続先へ勝手に変更しません。Goの1回の出力上限は翻訳8,000トークン、用語集2,400トークンです。上限等で未完了の応答は字幕・用語集として採用しません。長いファイル入力では上限に達することがあります。

**Goの利用条件に注意:** [公式ドキュメント](https://opencode.ai/console/go)はGoをコーディングエージェント向けとしています。この動画翻訳アプリの用途が許可されるかは、利用前に提供元へ確認してください。利用可能性は未確認です。アプリ固有のUser-Agentと会話単位の`x-opencode-session`を送信し、コーディングエージェントの偽装、利用制限の回避、別の有料APIへの自動切り替えは行いません。403では利用権限・契約・用途を確認するよう表示します。エンドポイントとモデルIDは[公式ソース](https://github.com/anomalyco/opencode/blob/dev/services/www/src/docs/content/console/go.mdx)で確認しています。

どちらも**翻訳と自動用語集生成は同じ接続先・モデル**を使います。設定変更後はサーバーを再起動してください。画面左側にモデル・認証方式・設定不足を表示します。「設定あり」は認証・残り利用枠まで検証した意味ではありません。

この切り替えはサーバー全体の設定で、再起動時に回復する未完了処理にも適用します。切り替え前に録音を停止し、未送信0・処理完了を確認してください。既存の用語集・手動修正はプロバイダー間で共通のまま保持します。新しいモデルで作り直す場合は「再生成」を押します。過去の翻訳は変更せず、翻訳ごとのプロバイダー・モデル名をSQLiteへ保存します。

### Whisperモデル

`.env`の初期値はCPUでも動かしやすい多言語`small`です。

```env
WHISPER_MODEL=small
WHISPER_DEVICE=cpu
WHISPER_COMPUTE_TYPE=int8
```

NVIDIA GPUと十分なVRAMがある場合は次を検討できます。

```env
WHISPER_MODEL=large-v3-turbo
WHISPER_DEVICE=cuda
WHISPER_COMPUTE_TYPE=float16
```

モデルは`pnpm whisper:start`の初回起動時にダウンロードされます。

## 起動

Whisper、TypeScriptサーバー、Web UIをまとめて起動します。

```powershell
pnpm dev:local
```

ブラウザで <http://127.0.0.1:5173> を開きます。ターミナルで起動した場合は、Ctrl+Cでまとめて停止できます。

APIの既定ポートは8787です。他のアプリが使用中なら、`.env`の`PORT=8788`などに変更して再起動してください。ViteのHTTP/WebSocket転送先も同じ`PORT`に追従するため、別アプリを停止する必要はありません。Whisperの既定ポートは8790で、変更する場合は`WHISPER_PORT`と`WHISPER_URL`を合わせて変更します。

個別に起動する場合:

```powershell
# Terminal 1
pnpm whisper:start

# Terminal 2
pnpm dev
```

### YouTubeを翻訳する

1. 入力元の「YouTube」を選ぶ
2. 「YouTubeの動画URL」にURLを貼り付け、「動画を表示」を押す
3. 左側の「翻訳を開始」を押す
4. Chrome/Edgeの共有画面で、**このアプリを開いているタブ**を選ぶ
5. **「タブの音声を共有」**を有効にして共有を開始する
6. ページ内のYouTubeプレーヤーを再生する。原文・翻訳はその下に表示される

別のYouTubeタブを開く必要はありません。最後に表示した動画URLはブラウザ内へ保存します。録音中は動画URLの変更や入力元の切り替えを無効にします。

YouTubeの埋め込みは別オリジンのため、アプリから動画の音声を直接読み取ることはできません。音声取得には引き続き、利用者によるタブ共有の許可が必要です。対応ブラウザでは現在のタブを共有候補として優先し、ローカル再生音声を抑制しないよう指定していますが、実際の共有・音声再生の挙動はブラウザに依存します。画面全体やウィンドウの共有は受け付けません。

投稿者が埋め込みを禁止した動画、年齢・地域などの視聴制限がある動画は、プレーヤー内で再生できない場合があります。YouTube URLからの直接ダウンロード、共有許可の回避、PC全体の音声取得は行いません。

### 保存済みの字幕を開き直す

確定した原文・訳文はサーバーのSQLiteへ保存します。画面のURLにも`?sessionId=...`を付けるため、そのURLをブックマークすれば同じセッションを開き直せます。**同じサーバーへアクセスしていれば、別ブラウザやブラウザ内の復元情報がない状態でも、そのリンクから表示できます。**

通常のURLでは、ブラウザ内に保存した最後のセッションIDを使います。一時的なネットワーク障害・サーバー停止・503などで、この復元IDを削除しないようにしています。復元エラーが出た場合は、サーバーの接続を確認して再読み込みしてください。

- 「新規」は画面・最後のセッションID・URLのセッション指定をクリアしますが、サーバーの保存データは削除しません。以前のリンクから再表示できます。
- 新しい録音・ファイル入力を始めると、URLも新しいセッションへ切り替わります。
- 保存済み字幕を開いても録音や音声共有は自動再開しません。録音中のリロードでは未確定・未送信部分を取りこぼす可能性があるため、先に録音停止と処理完了を確認してください。
- 過去のセッションを選ぶ履歴一覧は、まだありません。残したいセッションのURLを控えてください。

### 話題・用語集は自動で作成します

動画を表示すると、追加の入力なしに次の処理を開始します。

1. YouTube oEmbedから**タイトルとチャンネル名**を取得する。YouTube APIキーは不要です。
2. 翻訳と同じ選択済みプロバイダー・認証で、短い話題説明と用語集の候補を生成する。
3. 録音開始後、最初の確定発話から見直し、その後は約6チャンク（通常30秒分）ごとに、直近8発話の原文を使って更新する。
4. 用語集の原語をWhisperのヒントへ、話題・用語・訳語を翻訳モデルへ反映する。

生成はバックグラウンドで行うため、完成を待たずに「翻訳を開始」できます。生成失敗、タイムアウト、動画情報の取得失敗でも字幕処理は停止せず、既存の情報を使います。JSON／項目の形式だけが不正な場合に限り、同じ接続先・モデルで1回だけ再生成します（共通の30秒期限内、最大2リクエスト分の利用枠を使います）。認証・権限・利用枠・通信エラーや出力上限は自動再試行しません。選択したプロバイダーの認証が未設定の場合は、文字起こし・保存まで進み、翻訳は待機します。認証設定後はサーバーを再起動し、「再生成」で再試行できます。認証拒否や利用枠エラー時にも、別の接続先へは切り替えません。

左側の「話題・用語集」を開くと、根拠、候補、エラーを確認できます。

- **確認・編集 → 保存して固定**：手動の内容を優先し、自動更新を停止します。生成途中の古い結果でも上書きできません。
- **自動生成に戻す**：再びAIで更新します。
- 手動編集はこれから開始する認識・翻訳に適用し、過去の字幕は書き換えません。
- 話題を空欄、用語を0件にして手動固定すれば、用語補助なしで比較できます（直近の会話文脈は引き続き利用します）。
- 内容はSQLiteに**動画ID＋翻訳先言語**ごとに保存し、同じ動画・言語で再利用します。ページ再読み込みやサーバー再起動でも保持されます。
- 同時編集で内容が変わっていた場合は、下書きを残して競合を通知します。最新の内容を確認して再保存してください。

**自動生成は動画を全編視聴した要約ではありません。** 説明文・YouTube字幕・外部ドキュメントは取得していません。タイトルだけにない製品名は、実際の認識文に出現してから候補になります。初出の固有名詞がWhisperで誤認識された場合など、手動修正が必要なことがあります。生成する用語は最大20語に制限し、動画情報・実際の原文にない新規用語は採用しません。翻訳では原文を優先し、用語集にあるという理由で発言にない説明を追加しないよう指示していますが、AIの正確さを保証するものではありません。

音声は標準構成でローカルに留まります。一方、動画IDはYouTubeへ、取得したタイトル・チャンネル名と文字起こし・用語集は選択中の翻訳プロバイダーへ送信されます。用語集生成にもその契約の利用枠・料金が適用されます。Go側の「Use balance」等、提供元の課金設定はアプリでは変更・制御しません。データ保持・学習利用の条件はプロバイダーと選択モデルの最新ポリシーを確認してください。

## 認証の解除

```powershell
pnpm auth:openai:logout
```

## 確認コマンド

```powershell
pnpm typecheck
pnpm test
pnpm build

# 初回のみ、テスト用Chromiumをインストール
pnpm --filter @realtime-translate/web exec playwright install chromium
pnpm test:e2e
```

`test:e2e`は本番ビルド後、専用ポート18787と一時SQLiteでブラウザテストを実行します。画面、実際の音声変換・保存・WebSocket・バックグラウンド処理を通しますが、YouTubeプレーヤー、共有デバイス、Whisper、翻訳モデルはテスト用の代替です。Goアダプターのテストは実SDKから送られるHTTPを代替し、エンドポイント・認証・ヘッダー・エラー時の非切り替えを検証します。実際の認証や動画音声まで検証したことにはなりません。実機での確認手順は[docs/verification.md](docs/verification.md)を参照してください。

## 構成

```text
apps/web                 React / AudioWorklet / IndexedDB / WebSocket
apps/server              Node.js / SQLite / OpenAI OAuth・API / OpenCode Go / 話題・用語集の生成
packages/contracts       DTO、イベント、バイナリ音声フレーム
services/whisper         faster-whisperローカルサイドカー
scripts/whisper.mjs      Whisperセットアップ・起動
architecture.html        アーキテクチャ可視化
```

保存先は`data/realtime-translate.sqlite`（セッション・字幕・話題・用語集）、`data/audio/<session-id>/`、`data/auth.json`です。既存のDBは起動時に追加マイグレーションします。録音停止時は最終音声の連番も通知するため、アップロードが遅れていても早まって処理完了にはしません。

## pi durable

`pi durable`はまだ実行時依存に入れていません。将来、要約や複数ツールを使う長時間AI分析を追加するときに、`WorkflowRuntime`の任意アダプターとして独立パッケージへ導入します。音声取り込み、ASR、翻訳、アプリケーションDBの正本には使用しません。
